# 🚀 SpaceX Falcon 9 First Stage Landing Prediction

## 📌 Project Overview
This repository contains the final project for the **IBM Applied Data Science Capstone** on Coursera.  
The objective of this project is to analyze historical SpaceX Falcon 9 launch data and predict whether the first-stage booster will successfully land after launch.

Successful booster recovery plays a key role in reducing launch costs and improving mission efficiency.

---

## 🎯 Project Objectives
- Analyze SpaceX Falcon 9 launch data
- Identify factors influencing first-stage landing success
- Perform exploratory data analysis using Python and SQL
- Build interactive visual analytics using Folium and Plotly Dash
- Train and evaluate machine learning models to predict landing success

---

## 📊 Data Sources
- **SpaceX REST API** – Launch, rocket, payload, and landing data  
- **Wikipedia Web Scraping** – Historical Falcon 9 launch records  
- **SQLite Database** – Structured SQL-based analysis  

---

## 🛠️ Tools & Technologies
- Python (Pandas, NumPy)
- SQL (SQLite)
- Data Visualization (Matplotlib, Seaborn)
- Interactive Mapping (Folium)
- Dashboard Development (Plotly Dash)
- Machine Learning (Scikit-learn)

---

## 🔍 Project Workflow
1. Data Collection using SpaceX API and Web Scraping  
2. Data Wrangling and Feature Engineering  
3. Exploratory Data Analysis (Visualization & SQL)  
4. Interactive Map Visualization using Folium  
5. Interactive Dashboard using Plotly Dash  
6. Machine Learning Model Training and Evaluation  
7. Final Presentation and Reporting  

---

## 🤖 Machine Learning Models Used
- Logistic Regression  
- Support Vector Machine (SVM)  
- Decision Tree Classifier  
- K-Nearest Neighbors (KNN)  

**Best Performing Model:**  
K-Nearest Neighbors with approximately **89% accuracy**

---

## 📈 Key Insights
- Landing success improves over time as flight experience increases  
- Payload mass, orbit type, and launch site strongly influence landing success  
- Certain launch sites and orbits demonstrate higher reliability  
- Interactive dashboards enhance data-driven decision-making
